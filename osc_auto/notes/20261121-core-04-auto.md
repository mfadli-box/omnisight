# CORE 04 — Agent OmniSight

Tanggal 2026-11-21

## Tujuan dan cakupan

Menjalankan agent Go Linux/Ubuntu dan Windows tanpa CGO, mengirim heartbeat ke `osc_rest`, dan menyediakan diagnostik lokal dengan allowlist tetap.

## Hasil

- CLI membaca `agent.yaml` dan menerima override `HUB_URL`, `NODE_ID`, `AGENT_SECRET`, serta `POLL_INTERVAL_SEC`. Mode JSON sebelumnya tetap tersedia dengan `--config`.
- Worker mengirim OS, uptime, CPU%, RAM%, dan disk% ke `POST /baas/v1/agents/heartbeat`. Tanda tangan HMAC-SHA256 mencakup ID node, timestamp Unix, dan byte JSON yang dikirim. Panduan konfigurasi dan format tanda tangan ada di [README agent](../osc_auto/README.md).
- `osc_rest` mendaftarkan rahasia per node melalui objek JSON `AGENT_HEARTBEAT_SECRETS`, menerima selisih jam hingga 120 detik, dan menyimpan sampel terbaru per node di Valkey dengan TTL 900 detik. Validasi timestamp dan penggantian sampel di Valkey berlangsung atomik. Penyimpanan histori metrik dan perubahan status node di PostgreSQL berada di luar cakupan heartbeat ini.
- CLI menyediakan `uptime`, `df`, `docker ps`, dan `systemctl status`. Executor menetapkan executable dan argumen, membatasi durasi serta output, dan memeriksa daftar layanan lokal. Windows memakai kueri layanan Windows untuk `systemctl status`. Pada mode YAML, pemanggilan diagnostik melalui CLI.
- Unit systemd dan installer Windows Service menerima konfigurasi YAML dan menggunakan identitas layanan berprivilege rendah.

## Verifikasi

- `make build-agent` menghasilkan biner Linux amd64 dan Windows amd64 dengan `CGO_ENABLED=0`. `go test ./...`, `go vet ./...`, `cargo check --locked --offline`, `cargo test --locked --offline --lib`, dan `docker compose config --quiet` lulus.
- Smoke test memakai biner Go Linux, router heartbeat produksi dari `osc_rest`, dan Valkey sementara. Heartbeat awal dan berkala tersimpan, TTL sesuai, dan proses Go berhenti bersih saat SIGTERM. Timestamp lama, node asing, tanda tangan salah, replay, serta body rusak atau terlalu besar ditolak.
- CLI lulus uji override environment, konfigurasi environment-only, penolakan field YAML yang tidak dikenal, eksekusi `uptime` dan `df`, serta penolakan variasi command dan layanan di luar allowlist.
- `systemd-analyze verify` lulus dengan unit sementara yang menunjuk ke biner hasil build. Instalasi layanan systemd dan Windows Service pada host tujuan belum dijalankan. Verifikasi Windows sebatas cross-build.

## Operasi dan rollback

Jalankan satu agent per ID, sinkronkan jam node dan hub, dan gunakan HTTPS di luar loopback. Simpan konfigurasi dan rahasia sebelumnya saat upgrade. Jika perlu rollback, pasang kembali biner, konfigurasi, dan wrapper sebelumnya. Untuk instalasi mode JSON, pertahankan direktori state agar riwayat replay dan hasil job yang belum dikirim tetap tersedia.
