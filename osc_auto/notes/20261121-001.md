# CORE 04 — Agent dan heartbeat

Tujuan pekerjaan ini adalah menghubungkan agent Go tanpa CGO ke `osc_rest` pada Linux/Ubuntu dan Windows.

Cakupan meliputi konfigurasi YAML dan environment, heartbeat HMAC-SHA256 dengan replay protection, empat perintah diagnostik dengan allowlist tetap, serta wrapper systemd dan Windows Service. Mode JSON sebelumnya tetap tersedia.

Build Linux dan Windows lulus. Smoke test Go ke penerima `osc_rest` dan Valkey lulus, termasuk penolakan replay. Unit systemd lolos verifikasi statis. Windows Service belum dijalankan di host Windows.

Lihat [catatan CORE 04](20261121-core-04-auto.md) untuk kontrak, rincian verifikasi, dan rollback.
