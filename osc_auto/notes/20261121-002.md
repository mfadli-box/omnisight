# Collector telemetri agent

Worker YAML dengan `telemetry_enabled` mengirim metrik host, hasil S.M.A.R.T. serta statistik Docker lokal dengan HMAC. Platform Linux memakai procfs/sysfs dan Windows memakai counter native dan CIM. Tes pengiriman bertanda tangan dan cross-build Windows amd64 lulus. Prasyarat perangkat ada di [catatan Beszel](../../notes/20261121-01-beszel.md).
