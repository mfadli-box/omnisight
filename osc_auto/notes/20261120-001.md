# 2026-11-20-001 — Agen OmniSight lintas platform

## Tujuan

Menerapkan permintaan agen `ai-auto`: telemetri dan heartbeat node, komunikasi backend terautentikasi, pemeriksaan kesehatan bertanda tangan dan ber-allowlist, pelaporan persisten, integrasi systemd Linux dan Windows Service, serta build lintas platform.

## Keputusan

- Memilih Go 1.27.4 dan `golang.org/x/sys` v0.50.0, toolchain stabil dan modul x/sys terbaru yang tersedia pada 2026-11-20. Container lokal memiliki Go 1.26.6, sehingga repositori menetapkan toolchain yang lebih baru beserta perilaku unduh otomatis.
- Memisahkan paket domain/application dari pembungkus layanan OS dan pengumpulan metrik.
- Mengautentikasi transport dengan token bearer HTTPS per node; job diautentikasi terpisah memakai HMAC-SHA256 atas byte payload JSON persis dengan kunci 32 byte per node.
- Menyimpan sequence heartbeat, identifier replay, dan antrean hasil dalam berkas state dengan izin terbatas yang diganti secara atomik. Hanya satu proses per node/direktori state yang didukung.
- Hanya menyediakan `system.health` dan `service.status` yang diizinkan secara lokal; pemanggilan memakai executable OS tetap tanpa mengurai shell.
- Agen mengirim hasil ke rute backend. Backend diharapkan mengarsipkan output ke RustFS; kredensial object storage tidak didistribusikan ke store.
- Menambahkan penguatan systemd dan pengaturan LocalService/ACL Windows.

## Hasil

Menambahkan `osc_auto/cmd/agent`, layanan domain dan application, validasi konfigurasi, sampler telemetri Linux/Windows, adapter status layanan dan lifecycle khusus platform, klien API HTTPS, verifikasi HMAC, state replay/antrean hasil persisten, konfigurasi contoh, berkas deployment, target build Makefile, dan dokumentasi operator.

Jalur kontrak backend didokumentasikan di `osc_docs/planning/01_core_specs.md`, tetapi handler `/agent/v1/*` dan autentikasi token node terkait belum diimplementasikan di `osc_rest`; agen memerlukan rute tersebut sebelum deployment langsung.

## Verifikasi

- Memverifikasi build Linux/amd64 dan Windows/amd64 dengan `CGO_ENABLED=0` memakai compiler Go 1.26.6 terpasang pada salinan sementara dengan direktif modul yang disesuaikan untuk verifikasi lokal. `go.mod` akhir tetap menetapkan Go 1.27.0 dan toolchain 1.27.4.
- Build langsung terhadap modul akhir tidak dapat mengunduh Go 1.27.4 karena cache toolchain hanya-baca di lingkungan ini. Tidak ada pengujian yang ditambahkan atau dijalankan.
- Memastikan konfigurasi contoh tidak berisi kredensial sungguhan.
