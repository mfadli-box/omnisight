# Catatan kerja 20261120-002

## Tujuan dan hasil

Tetapkan alamat Docker `172.99.55.*` untuk development, test, dan validation. `make up-dev` memakai bridge Compose dengan subnet `172.99.55.0/24`. Pada host dengan `blackbox` eksternal di `172.99.0.0/16`, gunakan `make up-dev DEV_NETWORK=blackbox` untuk menetapkan IP `172.99.55.11`–`172.99.55.15`. Perintah `make down-dev` menerima opsi yang sama.

## Verifikasi

Konfigurasi Compose untuk kedua mode berhasil dirender dan diperiksa untuk kelima layanan. Pada daemon uji, jaringan `blackbox` mencakup subnet calon bridge terpisah sehingga Docker menolak membuat bridge tersebut. Satu kontainer Valkey sementara berhasil menerima IP `172.99.55.12/16` lewat konfigurasi bersama. Kontainer dan volume uji sudah dibersihkan.
