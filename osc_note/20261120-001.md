# Catatan kerja 20261120-001

- **Tujuan:** Membuat dan menjalankan skrip inisialisasi monorepo OmniSight sesuai permintaan di `runner.txt`.
- **Cakupan:** Enam panduan skill spesialis; kerangka direktori base, REST, site, automasi, dan dokumentasi; berkas awal REST/site/Go; Makefile; layanan Docker Compose; Dockerfile REST/site multi-stage non-root; template reengineering yang dapat digunakan ulang.
- **Keputusan:** Skrip idempoten dan disimpan sebagai `omnisight.txt` sesuai permintaan; Compose membaca secret dari environment. Hasil yang diminta adalah kerangka dan belum mengimplementasikan seluruh spesifikasi bisnis. Layanan runtime masih berupa aplikasi awal.
- **Hasil:** Direktori dan berkas awal yang diminta telah dibuat. Backend awal menyediakan `/health`; healthcheck Compose mencakup PostgreSQL, Valkey, RustFS, REST, dan site.
- **Verifikasi:** `bash -n omnisight.txt` dan `bash omnisight.txt` selesai dengan sukses. Build Docker dan validasi runtime Compose belum dijalankan.
- **Referensi versi yang diperiksa:** Lini image PostgreSQL 18 berdasarkan [catatan rilis resmi](https://www.postgresql.org/docs/release/); Node.js 26 LTS berdasarkan [jadwal rilis resmi](https://nodejs.org/en/about/previous-releases); Go 1.26 berdasarkan [riwayat rilis resmi](https://go.dev/doc/devel/release); endpoint readiness RustFS berdasarkan [dokumentasi pemeriksaan status resmi](https://docs.rustfs.com/en/operations/status-check).
