# Catatan kerja 20261120-001

- **Tujuan:** Membuat migrasi skema PostgreSQL berurutan dan data seed awal untuk OmniSight.
- **Cakupan:** Hierarki tenant, field identitas/MFA, model role dan privilege modul, tabel transaksi, log aktivitas append-only, fungsi/policy RLS, dan data seed contoh.
- **Keputusan:** Menambahkan `osc_role_menu` agar hak modul perusahaan dan grant aksi level role terpisah. `area_id` bernilai `NULL` pada akses pengguna berarti semua area aktif di perusahaan tersebut; catatan transaksi tingkat perusahaan juga dapat memakai `area_id NULL`. Super Admin dibuat sebagai placeholder bootstrap lokal nonaktif tanpa hash kata sandi; provisioning tepercaya harus memasang hash Argon2id sebelum aktivasi.
- **Keamanan:** Cakupan RLS menolak secara aman konteks perusahaan yang hilang/tidak valid, perusahaan/area nonaktif, dan area yang tidak tercantum dalam GUC daftar area yang diizinkan. Role DB runtime tidak boleh memiliki tabel atau `BYPASSRLS`; activity log menolak UPDATE/DELETE/TRUNCATE. Rahasia hanya direpresentasikan sebagai byte terenkripsi atau referensi kredensial eksternal.
- **Hasil:** Menambahkan `001_apps.sql` sampai `005_init.sql` dan `seeds/001_initial_seed.sql`.
- **Verifikasi:** SQL ditinjau untuk urutan migrasi, key, check, referensi, cakupan RLS, dan konsistensi seed. Eksekusi PostgreSQL, replay migrasi, uji integrasi RLS, dan uji trigger belum dijalankan.
