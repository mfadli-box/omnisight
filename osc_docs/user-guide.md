# User Guide - OmniSight

Panduan penggunaan OmniSight untuk end-user.

## 1. Overview

OmniSight adalah platform manajemen ICT terintegrasi.

## 2. Getting Started

1. Akses aplikasi di browser
2. Login dengan kredensial yang diberikan
3. Pilih company jika diperlukan

## 3. Fitur Utama

- Dashboard & Widget
- File Management (akses file melalui /files)
- Modul per aplikasi (APP00–APP05)
- Sistem (SYS01–SYS03)

## 4. Bantuan

Hubungi admin sistem untuk bantuan.
