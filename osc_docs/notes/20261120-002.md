# 2026-11-20-002 — Suite integrasi dan panduan operasi

## Tujuan

Menambahkan suite fungsional dan keamanan pytest + httpx yang diminta, serta panduan penggunaan harian dan runbook deployment di `osc_docs/`.

## Cakupan dan keputusan

- Menambahkan pengujian black-box terhadap API REST dan rute berkas yang menggunakan RustFS. Kredensial uji dibaca dari environment; tidak ada rahasia atau data pribadi yang disimpan di repositori.
- Menambahkan prasyarat fixture eksplisit dan kontrak opsional controller skenario privat khusus pengujian untuk respons HRIS deterministik, status gangguan/circuit breaker, fixture DB yang dapat diubah, serta reset pembatas laju Valkey. Controller ini adalah infrastruktur pengujian, bukan endpoint produk; hanya boleh mengarah ke lingkungan yang dapat dibuang.
- Mengikuti perilaku rute `osc_rest` saat ini: path SOP singular `/sop/documents/{id}/attachment`, request PDF memakai `table_name`. Perbedaan terhadap kontrak desain yang mendokumentasikan path attachment plural dan payload PDF berbasis template dicatat.
- Mendokumentasikan semantik skip pytest agar fixture yang hilang tidak disalahartikan sebagai pengujian yang berhasil.
- Mendokumentasikan paket deployment Go Agent yang tersedia, akun layanan, persistensi state, provisioning rahasia, batas jaringan multi-VM, pemeriksaan kesehatan, upgrade, dan pemulihan.

## Hasil

- `osc_docs/test_flow/test_core_flows.py` mencakup login lokal; provisioning/penolakan HRIS; circuit breaker dengan cache yang belum/kadaluarsa; enrollment dan verifikasi TOTP serta reset sekali pakai dengan backup code; perpindahan company/area; navigasi; upload/download SOP; serta struktur ZIP/XLSX dan PDF.
- `osc_docs/test_guard/test_security_guards.py` mencakup target SSRF IP privat/metadata, XXE dan XML >64 KiB, replay TOTP dan pembatasan percobaan, penegakan MFA/step-up PAM, serta IDOR lintas tenant/area.
- Menambahkan dependensi suite, konfigurasi pytest, dokumentasi fixture, `01_USER_GUIDE.md`, dan `02_DEPLOYMENT_RUNBOOK.md`.

## Verifikasi

- `python3 -m py_compile` berhasil untuk kedua modul pengujian.
- Perintah `python3 -m pytest -q -c osc_docs/pytest.ini osc_docs/test_flow/test_core_flows.py osc_docs/test_guard/test_security_guards.py` mengumpulkan 17 kasus; semuanya dilewati karena lingkungan ini tidak menyediakan API uji, akun uji, atau fixture controller. Tidak ada perilaku API/keamanan live yang diklaim telah diverifikasi.
- Suite integrasi memerlukan deployment terisolasi dan environment variable yang dijelaskan di `osc_docs/test_flow/README.md`; controller fixture eksternal belum dibuat dalam pekerjaan dokumentasi/pengujian ini.
