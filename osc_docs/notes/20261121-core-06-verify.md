# 2026-11-21 Core 06 — Smoke test dan verifikasi Docker

## Tujuan

Memverifikasi alur inti OmniSight pada stack Compose dan menguji penolakan
akses pada kontrol autentikasi, PAM, dan HRIS.

## Cakupan dan keputusan

- `test_core_e2e.py` mengikuti healthcheck, public companies, login Super Admin,
  navigasi, pemilihan company/area, pembuatan SOP, unggah dan unduh lampiran
  RustFS, daftar SOP, ekspor XLSX RP01, dan pembuatan PDF RP02. Fixture demo
  memiliki satu company. Skenario ini tetap menguji perpindahan ke area
  terpilih dan kembali ke cakupan company-wide. Company kedua dapat dipilih
  jika akun uji memiliki akses.
- Kontrak saat ini memetakan konektor eksternal ke SA04 dan pembacaan
  `GET /baas/v1/audit-logs` ke izin SA03. Suite membaca kedua endpoint dan
  mencocokkan aksi audit dengan aktor, area, dan ID objek yang dibuat saat uji.
- `test_core_security.py` memeriksa penolakan pada tujuh rute terlindungi tanpa
  kredensial, dengan JWT rusak, dan dengan cookie sesi rusak. Pengujian PAM
  memakai akun tanpa MFA, memerlukan izin OP01, dan mengharapkan
  `403 MFA_REQUIRED_FOR_PAM`.
- Guard SSRF menguji respons `400 INVALID_INPUT` saat konfigurasi konektor
  menerima calon endpoint di luar kebijakan host. Guard XXE menjalankan
  regresi parser Rust dari pytest. Regresi mencakup respons HRIS biasa,
  penolakan DTD kosong, dan XML yang melampaui batas ukuran.
- Compose untuk verifikasi memakai proyek sementara, jaringan bridge proyek,
  port loopback otomatis, serta migrasi dan seed demo pada volume baru.
  Kata sandi akun fixture dibuat untuk eksekusi tersebut dan diteruskan
  melalui environment. SOP, arsip laporan, dan target PAM fixture berada di
  volume uji sementara.

## Hasil verifikasi

- `docker compose config --quiet` berhasil untuk Compose utama dan konfigurasi
  isolasi. `docker compose up -d --build --wait` membangun image REST dan web
  memakai cache yang tersedia. Kelima layanan mencapai status `healthy`.
- `python3 -m py_compile` berhasil untuk kedua file pytest.
- Pytest mode ketat melaporkan **11 lulus, 0 dilewati** dalam **2,05 detik**.
  Ini mencakup round-trip lampiran RustFS, struktur XLSX, signature dan EOF PDF,
  entri audit terkait, penolakan PAM, validasi konfigurasi SSRF, dan regresi
  parser XML.
- Kontainer, volume, dan jaringan proyek sementara berhasil dihapus seusai
  pengujian.
- Login end-to-end ke upstream HRIS dan perilaku jaringan runtime SSRF belum
  dijalankan. Bukti HRIS berasal dari validasi konfigurasi REST dan regresi
  langsung pada parser produksi.

Perintah pytest dengan `OMNISIGHT_TEST_API_URL` dan kredensial fixture sudah
diatur di environment.

```sh
OMNISIGHT_TEST_REQUIRE_FIXTURES=1 python3 -m pytest -q -c osc_docs/pytest.ini \
  osc_docs/test_flow/test_core_e2e.py \
  osc_docs/test_guard/test_core_security.py
```
