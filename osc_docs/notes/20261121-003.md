Tujuan: menambahkan manajemen kontainer OP02 dan inventaris paket SA04, terinspirasi Arcane.

Cakupan dan keputusan: agent mengumpulkan snapshot bertanda tangan dan menjalankan aksi yang diizinkan melalui antrean OPS; REST menegakkan scope tenant dan RBAC; UI menyediakan tabel, filter, aksi dan tab SBOM. Status update image belum dibandingkan dengan registry. Detail penerapan dan batasan ada di `notes/20261121-03-arcane.md`.

Hasil: executor, API, migrasi dan UI ditambahkan.

Verifikasi: uji Go, cross-build Windows, uji Rust library dan typecheck UI lulus. Pengujian Docker/PostgreSQL end-to-end belum dijalankan.
