# Hub telemetri REST

Ingest mengautentikasi node, menyimpan sampel serta evaluasi alert dalam transaksi, lalu memperbarui heartbeat Valkey. GET riwayat memeriksa izin CT01 atau OP02 dan cakupan tenant. Uji Rust, SQL melalui PGlite, serta smoke test HTTP dengan PostgreSQL dan Valkey lulus. [Catatan Beszel](../../notes/20261121-01-beszel.md)
