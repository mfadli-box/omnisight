# Catatan kerja 20261120-001

- **Tujuan:** Menerapkan fondasi autentikasi dan MFA Clean Architecture di `osc_rest` menggunakan Axum, SQLx/PostgreSQL, dan Valkey.
- **Cakupan:** Lapisan domain/use case/port/infrastructure/presentation; login lokal dan HRIS ASMX; verifikasi Argon2id serta provisioning/fallback cache HRIS; allowlist host anti-SSRF, timeout HTTP 5 detik, batas stream 64 KiB, parser XML tanpa DTD; circuit breaker sliding-window di Valkey; setup/enable/verify/disable TOTP; reset MFA dengan backup code; token reset email; otorisasi reset admin; pencabutan token sesi; konfigurasi runtime dan integrasi role DB Compose.
- **Keputusan:** Format profil HRIS sukses diasumsikan `1|username|full_name|email` karena pemetaan field upstream belum ditentukan; asumsi ini didokumentasikan di `osc_rest/README.md`. Pengiriman email memakai adapter JSON HTTPS yang dikonfigurasi operator. Pencabutan sesi memakai watermark waktu terbit Valkey per pengguna karena skema belum memiliki tabel sesi persisten. Login API mengembalikan data token kepada BFF Next.js tepercaya untuk disimpan di cookie Secure HttpOnly. `LDAP_AD` dan `M365_OIDC` ditolak sebagai provider belum didukung, bukan dialihkan ke autentikasi lokal.
- **Integrasi DB:** Memperbarui `osc_base/migrations/005_init.sql` dan menambahkan migrasi lanjutan `006_auth_runtime.sql` agar hanya transaksi bisnis memakai RLS; pencarian control-plane identitas/hierarki/akses tetap khusus backend demi resolusi grant perusahaan sebelum autentikasi selesai. Menambahkan role `osc_app_runtime` tanpa login dan grant terbatas, serta inisialisasi Compose untuk login `omnisight_app`, agar API tidak memakai superuser PostgreSQL.
- **Keamanan:** URL dan body kredensial HRIS tidak pernah dicatat; redirect dinonaktifkan; input dibatasi dan deklarasi DTD/entity XML ditolak. Seed TOTP dienkripsi AES-256-GCM di PostgreSQL dan staging Valkey, backup code di-hash Argon2id, replay ditolak secara atomik, operasi MFA/reset mencabut sesi sebelumnya. Endpoint terlindungi menolak secara aman jika Valkey tidak tersedia.
- **Hasil:** Menambahkan berkas implementasi Auth/MFA, README konfigurasi, wiring role runtime Compose, dan catatan ini.
- **Verifikasi:** `cargo fmt --all`, `cargo fmt --all -- --check`, dan `cargo metadata --no-deps --format-version 1` berhasil. `cargo check` tidak dapat mengakses crates.io karena DNS jaringan tidak tersedia; `cargo check --offline` memastikan crate `redis` tidak tersimpan di cache. Uji integrasi runtime dan suite keamanan belum dijalankan.
- **Keputusan integrasi yang tersisa:** Provisioning secret JWT/MFA/email/PostgreSQL; validasi skema profil respons HRIS dan namespace XML provider; pastikan volume PostgreSQL yang ada membuat/memberi grant ke `omnisight_app`; jalankan migrasi sebagai owner dan API sebagai role non-owner; konfigurasi firewall egress intranet dan endpoint email.
