# Container inventory and SBOM API

Objective: support OP02 container management and SA04 package inventory from agent nodes.

Scope and decisions: store bounded, HMAC-authenticated snapshots with replay protection and tenant/store RLS; authorize OP02 inventory and mutations per area, using can_update for start/stop and can_delete for prune. Prune removes all stopped containers on the selected node. SA04 view permission gates SBOM. Jobs use the existing encrypted and signed agent queue. Migration 010 must be applied. Image update status remains unknown until registry comparison exists. Inventory and SBOM may be stale when agents are offline or collection fails.

Outcome: added snapshot ingest, list, SBOM and action endpoints, database migration, and container job integration.

Verification: cargo test --lib --offline passed (6 tests), including snapshot route body limits. PostgreSQL 18 applied migrations 009 and 010 against minimal prerequisite tables in a temporary schema and rolled back successfully; this does not verify production data or an end-to-end Docker integration.
