# Pengerjaan 2026-11-20-001

## Tujuan

Membangun aplikasi OmniSight `osc_site` dengan Next.js App Router, Tailwind CSS v4, komponen bergaya shadcn/ui, BFF autentikasi, navigasi dinamis berdasarkan privilege, dan halaman modul inti.

## Keputusan dan cakupan

- JWT akses dan tantangan MFA disimpan di cookie `HttpOnly; Secure; SameSite=Strict`. BFF tidak mengirim JWT pada body respons atau menyimpannya di penyimpanan browser. Rute yang mengubah state memvalidasi `Origin`.
- Rute BFF melayani login, verifikasi MFA, perpindahan company, logout, reset MFA melalui email, navigasi, PAM authorize, transfer lampiran SOP, dan ekspor laporan. Proxy laporan menerima tabel dari allowlist tetap.
- Workspace mengambil navigasi dari backend dan hanya menampilkan modul dalam daftar `can_view`. Sidebar desktop berubah menjadi drawer Radix pada layar kecil.
- Login mendukung Local Account, company contoh dari seed, UUID company lain, OTP enam digit, backup code, dan pemulihan email.
- Halaman CT01, OP01, OP02, KB01, RP01, RP02, SA01–SA04 dibuat responsif. Backend belum memiliki endpoint baca CT01/OP02, CRUD dokumen SOP, atau administrasi SA01–SA04; UI menandai telemetri sebagai contoh, menyediakan pratinjau Markdown lokal, dan menonaktifkan mutasi administrasi yang belum tersedia.
- Context switcher menyediakan daftar company contoh dan input UUID untuk deployment lain. REST belum menyediakan endpoint direktori company/area yang difilter berdasarkan grant pengguna.

## Hasil

- Menambahkan shell workspace, header, context switcher company/regional, sidebar/drawer navigasi, halaman login dan pemulihan, komponen bergaya Radix/shadcn, serta halaman modul inti.
- Menambahkan route handler BFF dan konfigurasi Next.js, Tailwind v4, TypeScript, Docker ignore, README, serta variabel `APP_ORIGIN` pada Compose.

## Verifikasi

- `tsc --noEmit --incremental false`: berhasil menggunakan cache dependensi lokal yang tersedia (Next 16.4.6, React 19.3, Tailwind 4.3.5, Radix Dialog 1.3.1).
- `npm install`: tidak dapat mengambil paket dari `registry.npmjs.org` karena DNS `EAI_AGAIN`; lockfile tidak terbentuk.
- `next build`: belum terverifikasi. Turbopack gagal membuat proses CSS di sandbox (`Operation not permitted`); fallback webpack berhenti saat Next mem-parsing konfigurasi TypeScript dari cache dependensi.
- Pengujian browser atau integrasi backend belum dijalankan.
