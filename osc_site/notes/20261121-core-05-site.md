# Core 05 · Workspace OmniSight

## Tujuan

Melengkapi aplikasi `osc_site` dengan autentikasi BFF, login MFA, AppShell mobile-first, integrasi modul inti, dan image standalone non-root.

## Cakupan dan keputusan

- Pertahankan kerangka Next.js 16 App Router, TypeScript, Tailwind v4, dan shadcn/ui. Tambahkan lockfile dan Docker build multi-stage dengan `npm ci` serta pengguna runtime `node`.
- Gunakan `INTERNAL_API_URL` untuk request REST server-side. Proxy memakai daftar endpoint dan metode yang diizinkan, membatasi ukuran body, dan memvalidasi origin mutasi. JWT sesi serta challenge memakai cookie `HttpOnly`, `Secure`, dan `SameSite=Strict`. Logout menghapus cookie browser. BFF tetap menerima `BACKEND_URL` sebagai fallback kompatibilitas.
- Login mengambil company dari `/baas/v1/public/companies`, mendukung Local Account, OTP enam digit, backup code, dan alur reset MFA. Path lama `/api/auth/verify-mfa` tetap menjadi alias `/api/auth/mfa-verify`.
- Tambahkan `GET /baas/v1/me/contexts` untuk daftar company dan area sesuai grant aktif. AppShell memuat navigasi efektif dari `/baas/v1/me/navigation` dan menggunakan Sheet pada layar mobile.
- Tambahkan `GET /baas/v1/agents/status` untuk OP02. REST memfilter node berdasarkan izin OP02 serta cakupan company dan area sebelum membaca heartbeat Valkey dengan UUID node. Metrik berlaku selama TTL cache 15 menit. Antrean scheduler belum memiliki API.

## Hasil

- CT01 menampilkan inventaris node. OP01 mengelola target dan otorisasi sesi PAM dengan OTP step-up. OP02 menampilkan heartbeat serta metrik CPU, RAM, dan disk.
- KB01 mengelola SOP dan lampiran. RP01 dan RP02 mengekspor XLSX dan PDF dengan akses ulang ke arsip privat.
- SA01 mengelola company, area, dan store. SA02 mengelola akun, pencabutan akses, dan reset MFA. SA03 menampilkan audit serta mengelola role dan privilege. SA04 mengelola provider dan TTL cache HRIS.

## Verifikasi

- `npm run typecheck`, `npm run build`, dan `docker compose config --quiet` lulus.
- Image Alpine lulus build dengan `npm ci`. Smoke test runtime memastikan proses non-root dan halaman `/login` merespons dari server standalone.
- Smoke test HTTP dengan REST fixture memeriksa guard origin, atribut cookie, OTP dan backup code, rotasi sesi, Bearer, unggah lampiran, PDF, dan logout. Chromium mobile memverifikasi login OTP, Sheet, tampilan kesepuluh modul, context switch, dan logout.
- `cargo fmt --check`, `cargo test --offline`, dan `git diff --check` lulus.
- Integrasi REST dengan PostgreSQL dan Valkey sementara memverifikasi login lokal, direktori konteks, OP02 tanpa izin CT01, penerimaan heartbeat bertanda tangan, dan isolasi metrik setelah perpindahan area.
